# 办公通讯录网站部署说明

本文档提供了如何部署办公通讯录网站的详细说明。

## 文件结构

```
address_book_package/
├── data/                  # 通讯录数据文件
│   ├── contacts.json      # 处理后的联系人数据
│   └── contacts_final.json # 最终优化的联系人数据
├── dist/                  # 构建后的静态网站文件
├── public/                # 公共资源文件
│   └── contacts.json      # 网站使用的联系人数据
├── src/                   # 源代码
│   ├── App.css            # 样式文件
│   ├── App.tsx            # 主应用组件
│   └── ...                # 其他源文件
└── ...                    # 其他配置文件
```

## 部署选项

### 选项1：部署预构建的静态文件（最简单）

1. 将 `dist` 目录中的所有文件上传到您的网站服务器
2. 配置您的服务器将所有请求路由到 index.html

对于大多数静态网站托管服务（如 GitHub Pages、Netlify、Vercel 等），只需上传 `dist` 目录的内容即可。

### 选项2：从源代码构建并部署

如果您想修改网站或更新数据，可以从源代码重新构建：

1. 确保您的环境中安装了 Node.js（推荐 v16+）和 pnpm
2. 在项目根目录运行以下命令：

```bash
# 安装依赖
pnpm install

# 构建项目
pnpm run build
```

3. 构建完成后，`dist` 目录将包含可部署的静态文件
4. 将 `dist` 目录中的所有文件上传到您的网站服务器

## 更新数据

如果您需要更新通讯录数据：

1. 修改 `public/contacts.json` 文件
2. 重新构建项目（如果使用选项2）
3. 或者，如果使用选项1，直接替换已部署网站中的 contacts.json 文件

## 自定义

您可以通过修改以下文件来自定义网站：

- `src/App.tsx`：修改网站功能和布局
- `src/App.css`：修改网站样式
- `public/contacts.json`：更新联系人数据

修改后需要重新构建项目（使用选项2的步骤）。

## 注意事项

- 网站完全在客户端运行，不需要后端服务器
- 所有数据都存储在 contacts.json 文件中，确保该文件格式正确
- 网站设计为响应式，可在手机、平板和电脑上良好显示
