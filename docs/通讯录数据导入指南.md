## 🚀 快速开始

### 1. 准备数据文件

支持的文件格式：
- **CSV文件** (推荐)：逗号分隔值文件
- **JSON文件**：标准JSON格式

### 2. 使用导入工具

```bash
# 进入scripts目录
cd scripts

# 创建示例CSV文件
node import-contacts.js --sample

# 从CSV文件导入
node import-contacts.js your-contacts.csv

# 指定输出文件
node import-contacts.js your-contacts.csv ../public/contacts.json
```

## 📊 数据格式要求

### CSV文件格式

**必需列：**
- `部门`：员工所属部门
- `姓名`：员工姓名

**可选列：**
- `手机`：手机号码
- `分机`：内部分机号
- `直线`：直拨电话

**示例CSV文件：**
```csv
部门,姓名,手机,分机,直线
技术部,张三,13800138000,8001,50328001
技术部,李四,13900139000,8002,50328002
市场部,王五,13700137000,8003,50328003
```

### 支持的列名别名

为了兼容不同的数据源，工具支持以下列名别名：

| 标准列名 | 支持的别名 |
|---------|-----------|
| 部门 | department |
| 姓名 | name, 名字 |
| 手机 | mobile, phone |
| 分机 | extension, ext |
| 直线 | direct, directline |

### JSON文件格式

```json
{
  "contacts": [
    {
      "id": "1",
      "部门": "技术部",
      "姓名": "张三",
      "手机": "13800138000",
      "分机": "8001",
      "直线": "50328001"
    }
  ],
  "departments": ["技术部", "市场部"],
  "total": 1,
  "fields": ["部门", "姓名", "手机", "分机", "直线"]
}
```

## 🛠️ 导入工具使用

### 命令行选项

```bash
# 显示帮助信息
node import-contacts.js --help

# 创建示例文件
node import-contacts.js --sample

# 基本导入
node import-contacts.js <输入文件>

# 指定输出文件
node import-contacts.js <输入文件> <输出文件>
```

### 使用示例

1. **创建示例文件**
   ```bash
   node import-contacts.js --sample
   ```

2. **从Excel导出的CSV导入**
   ```bash
   node import-contacts.js company-contacts.csv
   ```

3. **从现有JSON文件更新**
   ```bash
   node import-contacts.js backup-contacts.json
   ```

4. **导入到自定义位置**
   ```bash
   node import-contacts.js new-data.csv /path/to/output.json
   ```

## ❓ 常见问题

### Q: CSV文件中有中文乱码怎么办？
A: 确保CSV文件使用UTF-8编码保存。在Excel中，选择"CSV UTF-8"格式导出。

### Q: 如何处理Excel文件？
A: 
1. 在Excel中打开文件
2. 选择"文件" → "另存为"
3. 选择"CSV UTF-8 (逗号分隔)"格式
4. 使用导入工具处理CSV文件

### Q: 导入后数据没有显示？
A: 
1. 检查浏览器控制台是否有错误
2. 确认文件路径正确
3. 重新构建项目：`npm run build`
4. 重启开发服务器：`npm start`

### Q: 如何备份现有数据？
A: 
```bash
# 备份当前数据
cp public/contacts.json backup/contacts-$(date +%Y%m%d).json
```

### Q: 如何合并多个数据源？
A: 
1. 将所有数据整理到一个CSV文件中
2. 使用导入工具一次性导入
3. 或者编写自定义脚本合并JSON文件

## 📝 数据准备建议

### 1. 数据清理
- 统一部门名称格式
- 检查手机号格式
- 移除重复联系人
- 确保姓名完整

### 2. 部门规范
- 使用标准部门名称
- 避免特殊字符
- 保持命名一致性

### 3. 联系方式
- 手机号使用11位数字
- 分机号使用4位数字
- 直线号码包含区号
